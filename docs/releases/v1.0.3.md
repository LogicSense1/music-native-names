# Music Native Names 1.0.3

The first public source release of Music Native Names, a Rust/AppKit menu bar helper for
original-language song, artist, and album names in the native Apple Music app.

## Highlights

- Symbol-and-color status indicator: green music note, orange connection/waiting symbols,
  gray pause circle, and red error indicator. Accessible descriptions and tooltips provide details.
- About dialog with the version, MIT license, and GitHub project link.
- English-default and Chinese documentation, contribution guidance, and a donation area.
- Clean Rust source tree; old prototypes and local diagnostic data are excluded.
- Reproducible build instructions, CI checks, portable installer ZIP, and SHA-256 checksums.
- Retains the album artist and player-title fixes from local versions 1.0.1 and 1.0.2.

## Installation and compatibility

Download `MusicNativeNames-1.0.3-macos-arm64.zip`, extract it completely, then open
`install.command`. This installs the helper in `~/Applications` and enables login startup.
To uninstall, run the included `uninstall.command`.

**Experimental, Apple Silicon only.** Runtime integration was tested on macOS 27.0
(26A5425a) and requires an already SIP-disabled configuration plus Apple Command Line Tools.
Neither the app nor installer changes system protections. The bundle is ad-hoc signed and
is not Developer ID signed or notarized. Building from source is supported.

Only US-storefront catalog entry points are currently covered. Ambiguous or unsupported
resources retain their existing names. Lyrics and precomposed editorial headings are not translated.

## Validation

The release pipeline runs Rust tests, formatting and Clippy, native duration regressions,
arm64e bridge syntax checks, package signature/version checks, and documentation link checks.
CI does not attach to Music. Live runtime/UI compatibility remains specific to the tested Mac.
