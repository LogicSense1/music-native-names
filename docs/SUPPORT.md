# Support / Donate · 支持与打赏

Stars, reproducible bug reports, translations, and pull requests help this project grow.
欢迎通过 Star、可复现的问题反馈、翻译和代码贡献支持项目。

Financial donations are not configured yet. No payment destination is active.
打赏暂未开通，目前没有有效收款入口。

## Maintainer setup

1. Use GitHub Sponsors if the maintainer's account is eligible; Buy Me a Coffee is an optional
   alternative. Account enrollment, payout details, and identity checks remain with the owner.
2. Copy `.github/FUNDING.yml.example` to `.github/FUNDING.yml` and replace the commented examples
   with verified account handles or a verified payment page. Do not commit placeholders as live links.
3. Add payment QR images to `docs/assets/donations/` only after checking that each code belongs
   to the intended recipient. Keep bank details, identity documents, and credentials out of Git.
4. Update the final Support / Donate section in **both** README files, linking to the real page
   or images. Test each destination while signed out before publishing.

Suggested markup after verified URLs are available:

```md
[GitHub Sponsors](YOUR_VERIFIED_SPONSORS_URL) · [Buy Me a Coffee](YOUR_VERIFIED_DONATION_URL)
```

二维码可以放在该目录，并在两份 README 中同时展示。不要用示例二维码或未核实的账号替代真实收款信息。
